Pop animation on value change — clear visual confirmation
Keyboard never appears — pure stepper UX throughout
Haptic vibration on Log Set — closes the interaction loop

Design Principles
Speed First
Every interaction must complete in <5 seconds. Steppers over keyboards. One tap to confirm.
Accent Economy
Accent blue at max 10% of screen area. Directs attention, doesn't noise-pollute.
Data Clarity
Numbers are heroes. Mono font for all data values. Secondary info in --text-tertiary.
